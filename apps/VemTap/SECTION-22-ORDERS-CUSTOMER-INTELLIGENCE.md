# SECTION 22: ORDERS &amp; CUSTOMER INTELLIGENCE

## PROJECT CONTEXT

Design the complete mobile\-first Orders &amp; Customer Intelligence module for Vemtap\.

This module is not for POS transactions\.

POS handles staff\-generated sales\.

Orders handles customer\-generated requests\.

Examples:

- QR Menu Orders
- Service Requests
- Appointment Requests
- Booking Requests
- Product Requests
- Inquiry Requests

This module should focus on customer\-initiated interactions\.

# CRITICAL VEMTAP DIFFERENTIATOR

Most systems separate:

CRM

Analytics

Vemtap connects everything\.
