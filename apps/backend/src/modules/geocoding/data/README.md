# Nigerian areas list

`../nigeria-areas.data.ts` is generated, so don't edit it by hand. It lets the
location picker name a point or find a typed area without an outside service.

Sources, downloaded on 2026-11-06:

- [GeoNames](https://www.geonames.org/) `NG.zip`, licensed under CC BY 4.0
- [OpenStreetMap](https://www.openstreetmap.org/copyright) place data, licensed
  under the ODbL, for city areas GeoNames doesn't list

Both need crediting wherever the data is shown.
